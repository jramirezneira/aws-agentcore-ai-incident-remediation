# Componente: Amazon S3

## Tipo

Almacenamiento de objetos

## Bucket principal
s3://variosjavierramirez/TrafficDator_Madrid_output/

## Responsabilidad
Almacenar el histórico de tráfico.
Servir como origen de datos para Athena.

## Bucket de resultados
Athena utiliza un bucket independiente para OutputLocation.

## Errores frecuentes
* Bucket inexistente
* AccessDenied
* BucketPolicy incorrecta

## Remediaciones habituales
* Verificar existencia del bucket.
* Crear el bucket si no existe.
* Verificar permisos de escritura.
